# Delegation wrappers

opencode-fast is the first route for bulk work and groundwork (ruling of 2026-11-12): it runs `opencode run` on an OpenCode Go plan with a DeepSeek Flash model, refuses free models because they train on requests, and takes no secrets in prompts. ds-flash and ds-pro also default to the Go plan; `DS_AGENT_PROVIDER=deepseek` selects the direct metered API. Harder work stays on the Codex routes. codex-fast uses the subscription-backed Luna bulk tier; codex-strong uses the Sol tier for difficult work and review. For a long main run, `--hcom` starts a native headless Codex session through hcom (codex-hcom.py), prints its hcom name so peers can message it during the run, and waits for the completed turn; it has no timeout unless `--timeout` sets one. The Codex wrappers use the configured Codex provider and reject forbidden model selectors. The smaller codex-run.py route is described in the parent README. DeepSeek wrappers use the official metered provider, with separate spend authorization. No wrapper may select prime-inference, a prime-inference/* model, or its API; a failed provider check is a refusal, never a fallback.

Free models run only on public inputs, inside a sandbox with no view of the machine, and every quote they return is checked with [quote-check](../quote-check) before any finding is used. ensure-provider-bridge starts the chosen local provider bridge on demand.

The delegation wrappers emit one completion record through the executable named by `DELEGATE_TELEMETRY_EMITTER` in [runtime.env.example](runtime.env.example), by default `$HOME/.local/bin/telemetry-emit`. The sink receives `delegation`, a session ID, and a JSON payload as positional arguments. Emission is bounded to five seconds and fails open; an absent sink is a silent no-op.

Run `bash delegation/wrappers/test-classifier.sh` for the offline completion and quota-wall classifier checks. The dmux fixtures under tests/dmux/ require a local tmux installation and a throwaway Git repository; the protocol harness can run without a provider by using --skip-agent. Failure artifacts remain in scratch or the requested output directory. `python3 delegation/wrappers/test-hcom.py` exercises the `--hcom` mode of both Codex wrappers against a scripted hcom stub. `python3 delegation/wrappers/tests/dsh-agent-rc3.py` checks dsh-agent's log, model and provider verification against a fixture driver; `tests/dsh-agent-rc3-smoke.py` runs the installed pinned driver against a loopback model endpoint.
