# Delegation wrappers

codex-fast uses the subscription-backed Luna bulk tier; codex-strong uses the Sol tier for difficult work and review. They use the configured Codex provider and reject forbidden model selectors. The smaller codex-run.py route is described in the parent README. DeepSeek wrappers use the official metered provider, with separate spend authorization. No wrapper may select prime-inference, a prime-inference/* model, or its API; a failed provider check is a refusal, never a fallback.

Free endpoints may log prompts. Earlier free harnesses attached private context files despite their prompt instructions, so free-silo runs them in a bubblewrap jail with a fake HOME, no ordinary home files, and a cleared environment. Only the free-route API keys and the loopback search bearer enter the jail. The jail is the process cwd: `--in` copies reviewed public inputs in, and `--out` copies produced files to the requested directory after the run. Before use, `free-silo --verify` tests isolation of both the work tree and the configured private notes tree, plus the exact installed harness versions. Set `FREE_SILO_PRIVATE_NOTES_ROOT` to an existing absolute path as shown in [runtime.env.example](runtime.env.example); verification refuses to run without it. Every harness update requires a fresh verification. Its canary checks include positive controls so a missing canary proves the detector ran.

The host codex-search-bridge serves a SearXNG-shaped JSON API on loopback. A bearer token authenticates jail requests; the host runs search with its Codex login, which never enters the silo. ensure-provider-bridge starts the chosen local provider bridge on demand; bridge units are disabled at login. Two concurrent copies of one Codex login invalidated each other, so use one login per OS user and route search through the host bridge.

A free stealth model retired upstream. codex-union and omp-union therefore have no default model: supply a current slug with --model or their route-specific environment variable. These routes still require the silo and public inputs. omp-search and omp-inkling name their own free models. The free-silo example configurations define only the jail profile and local bridges; credentials belong in a private environment file.

The delegation wrappers emit one completion record through the executable named by `DELEGATE_TELEMETRY_EMITTER` in [runtime.env.example](runtime.env.example), by default `$HOME/.local/bin/telemetry-emit`. The sink receives `delegation`, a session ID, and a JSON payload as positional arguments. Emission is bounded to five seconds and fails open; an absent sink is a silent no-op.

Run `bash delegation/wrappers/test-classifier.sh` for the offline completion and quota-wall classifier checks. The dmux fixtures under tests/dmux/ require a local tmux installation and a throwaway Git repository; the protocol harness can run without a provider by using --skip-agent. Failure artifacts remain in scratch or the requested output directory.
