# Deployment templates

These systemd units describe the sync, snapshot, deadman, sweep, and MCP lifecycles. Replace every `@BRAIN_*@` token before installation: `@BRAIN_USER@` is the dedicated service account; `@BRAIN_HOME@` its home; `@BRAIN_BIN_DIR@` the installed script and binary directory; `@BRAIN_VAULT@` the server vault path; `@BRAIN_MCP_DATA@` a separate writable index directory; `@BRAIN_TOKEN_FILE@` a root-managed bearer token file; and `@BRAIN_MCP_INSTRUCTIONS@` a readable copy of [client instructions](../obsidian-mcp/instructions.example.md). Install the laptop user unit under the user's systemd directory. The named scripts (`brain-obsidian-sync`, `brain-snapshot`, `brain-deadman`) are host-provided interfaces; each should exit nonzero on failure. The snapshot script pushes only to a private remote, and deadman checks that a recent snapshot exists.

Install `brain-mcp.service.d/auth.conf.example` as an active drop-in. It passes the token as a systemd credential; the patched server refuses to start if the token file is missing or invalid. Install the instructions drop-in and point it at a file that tells clients the vault rules. The semantic drop-in is optional; the tool allow-list in the base unit does not expose semantic search. Keep the service bound to a private interface or behind an authenticated proxy, with the bearer gate active at the server too.

Install [roots.example.json](../roots.example.json) as the root configuration and set its path in `sweep.env`. It is one mapping from root name to `managed` or `mirror`; both allowed roots and mirror exclusions come from it. Update it in the same change as the vault rule book. Install a local classifier following [content-classifier.example.json](../content-classifier.example.json), with narrow patterns for content that belongs outside the shared vault. Set `BRAIN_CONTENT_CLASSIFIER_FILE`, `BRAIN_SWEEP_HOLDING`, `BRAIN_SWEEP_MANIFEST`, and `BRAIN_VAULT_HOST_PATH` before enabling the sweep; the service refuses an unset classifier or holding path, rather than silently skipping that branch. The holding tree and manifest stay outside the vault. The sweep defaults to a quiet period and can be previewed with `--dry-run`. Enable the snapshot, deadman, and sweep timers after their host scripts and environment are in place. Verify each job and check the server copy after a machine write.
