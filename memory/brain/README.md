# Shared Obsidian brain

This is a shared Obsidian vault with a root [rule book](vault-AGENTS.md). A local and a server copy merge through Obsidian Sync; a headless client keeps the server copy current. An hourly git snapshot and deadman timer give a separate recovery signal. After a quiet period, a sweep moves narrowly classified out-of-scope content into a holding tree with a manifest, then moves files under unknown or retired root folders into `5 Inbox/captures/`. Machine writes are read back from the server copy, since a successful local write alone does not prove convergence.

The layout uses `.base` tables over Markdown records throughout. The ruling of 2026-09-06 followed a concrete need: members needed to browse the same evidence as agents without a parallel spreadsheet. A root mirror was once flattened into captures when the prose allow-list was updated but the sweep list was not. [The sweep](sweep-retired-paths.py) now derives allowed roots and mirror roots from one mapping; [roots.example.json](roots.example.json) shows the contract. Update that mapping and the rule book together. [The classifier example](content-classifier.example.json) shows the separate narrow match contract; configure local patterns outside the vault. Mirrors and agent apparatus are excluded from classification. Keep one home per fact: durable team knowledge in the vault, open work in the issue tracker, and compact personal state and pointers in [OptMem](../optmem/README.md). A bridge treats the vault as its source of truth.

The [deployment templates](deploy/) cover the sync clients, snapshot and deadman timers, sweep, and MCP service. The [MCP patch and recipe](obsidian-mcp/README.md) put a bearer gate, server-enforced tool filter, change-only watcher, fast path lookup, and connect-time rule instructions around the server copy. The endpoint grants the listed write tools but excludes deletion. Keep tokens outside the vault.
