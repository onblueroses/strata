# OptMem method and checked selection

[OptMem](https://github.com/VictorTaelin/OptMem) is an upstream append-only memory project. This directory contains an independently added Bend proof and selection layer plus portable helpers. The upstream repository carries no license file, so obtain it separately and integrate these additions into that checkout only after resolving its terms. The changes an integration makes to upstream `memo`, its tests and its other files are described by the contract in [BEND_SELECTION.md](BEND_SELECTION.md).

An integrated checkout changes upstream `memo` to call the checked selector at wake, retain an explicit Python recovery path, and set the wake budget. Its `test.py` fixtures and budget assertion follow that setting; `.gitignore` excludes local build artifacts; the upstream `README.md` explains the selector; and `anim/render.js` changes the displayed context budget. These are the integration points. The actual note limit is UTF-8 bytes as enforced by `memo`, regardless of any character wording in upstream prose.

## Notes and lifecycle

The full writing and recall contract lives in [Knowledge Management](../../reference/knowledge-management.md). A note is one line, at most 280 UTF-8 bytes: `TYPE ENTITY SCOPE KEY PAYLOAD`. Types are `F` fact, `S` current state, `E` event, and `P` document pointer. Structural tokens use `@e/<entity>`, `@g` or `@s/<session-id>`, and `@k/<key>`. The newest numeric id for a given `(entity, scope, key)` is the live state; correct it by appending. Recall is regex, so narrow a truncated result until coverage is complete. A rich document lives in the notes tree first, followed by a `P` pointer. One fact has one authoritative home.

At session start, a [wake hook](../../claude/hooks/optmem-wake.sh) prints recent notes and core facts; its [core helper](../../claude/hooks/optmem-core.sh) maintains that selection. Primaries write through `memo note`; delegates return candidates. A detached delegate can use [optmem-proposals](optmem-proposals) for a primary to claim, judge, append, and archive. After enough new notes, wake requests a `memo nap` summary; the user-facing primary pays that debt before other work. A nap is an append, never an edit to past records. The proposal helper reads the canonical contract through `OPTMEM_CONTRACT_FILE` or this repository's reference path and stores queue files under `OPTMEM_DIR` or `$HOME/.optmem`. After an archive the helper hands one row of counts (`claimed`, `keep`, `rewrite`, `reject`) to the telemetry sink `OPTMEM_DRAIN_TELEMETRY_SINK`, by default `$HOME/.local/bin/telemetry-emit`, called with `optmem_drain`, a session id and the JSON counts. An absent sink is a silent no-op and a failing one never costs the archive. `OPTMEM_SESSION_ID` supplies the session id when available.

## Bend layer

[LAWS.bend](LAWS.bend) and the contract files state the cover, count, recovery, and preference invariants. [PROOF.bend](PROOF.bend) proves the named laws for the executable selection entry. Status zero carries the preferred-cut contract; recovery statuses preserve complete geometry and count with a visible warning. Proof does not cover compiler correctness, persistence, summarization, latency, or resource use. The C bridge checks the returned native layout again at the boundary. The independent rational and objective references supply finite test oracles. Run `bend guide`, then run `PROOF.bend --verdict` with the exact executable pinned in [BEND_TOOLCHAIN.json](BEND_TOOLCHAIN.json) before committing an integrated change. The full check and host integration requirements are in [BEND_SELECTION.md](BEND_SELECTION.md).

[optmem-freeze-watch.sh](optmem-freeze-watch.sh) observes a frozen migration tree by hashes, directory listing, and git history; set `FREEZE_REPO`, `FREEZE_STATE`, and `FREEZE_TRACKED_DIR`. It reports violations in JSONL without blocking writes. It was kept as a configurable migration tool because a read-only freeze needs evidence over time, not just file permissions.
