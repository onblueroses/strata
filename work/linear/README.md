# brain-linear

`brain-linear` is the pinned Linear access path for each agent runtime. `pickup <runtime>` returns open `for:<runtime>` tickets and the deliberating queue for `BRAIN_LINEAR_DECISION_TEAM_KEY` as JSON; `--summary` gives compact queue health, and `--full` adds bounded descriptions and comment counts. The example team key is `ABC`. `gql <query> [vars]` is the raw GraphQL escape hatch and accepts a literal value, `@file`, or stdin (`-`). Other commands pass through to a pinned `linearis` CLI. Comment bodies use `issues discuss <ticket> --body <text>`; callers must check exit status because failures can return JSON.

Authentication is either an API key from `BRAIN_LINEAR_KEY_FILE` or an app identity with `BRAIN_LINEAR_AUTH=client_credentials`, `BRAIN_LINEAR_CLIENT_ID`, and `BRAIN_LINEAR_CLIENT_SECRET_FILE`. The optional mode-0600 `<client-secret-file>.scopes` contains exactly `app:assignable,app:mentionable` to opt the app into assignment and mentions. Every caller of one app must use the same scopes file. App mode mints a token for each invocation and revokes it on exit; it never falls back to a key. Do not invoke this CLI as the dispatcher service account while that service runs, since token revocation can invalidate its concurrent Linear requests. See [env.example](env.example).
