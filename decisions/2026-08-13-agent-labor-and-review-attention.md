# Spend agent effort to protect review attention

Decided: 2026-08-13

Rule: Use enforceable checks for important invariants and let agents do the work needed to
      save the operator review time.

Reason: Agents followed executable gates more reliably than prose-only conventions. Counting
        agent effort as the main cost obscured the scarce review boundary.

Reopen when: Measured gate cost or review burden exceeds the failures and review time the
             check prevents.

Effect: Process is sized to actual risk rather than a blanket demand for ceremony.
