# Open shared vault lists as tables

Decided: 2026-09-06

Rule: In the shared Obsidian vault, give each list-bearing folder a table view and keep
      detailed records under that folder; use a small navigable top level.

Reason: Flat folders had become long lists that hid the reasoning. Hiding record folders with
        the application exclusion setting was tested and also removed those records from table
        queries.

Reopen when: Another layout stays easy to scan while preserving the table queries and record
             access under a realistic vault load.

Effect: A writer fixes obsolete paths at the writer instead of reviving the flat tree.
