# private-tokens.example.txt — template for your local leak inventory.
#
# strata-init copies this file to config/private-tokens.txt when that gitignored
# file is absent. Add one token per line: any string that, if it appeared in a
# public commit, would leak something you wanted private. The public-action and
# pre-push gates read it before posting or pushing public content.
#
# Tokens are matched as fixed strings (grep -F), case-insensitive (grep -i).
# Lines starting with # are comments and ignored.

# === Identity ===
# Your full name
# Your email address
# Your handle on platforms that map to your real name

# === Private business / project names ===
# Internal project codenames not on public profiles
# Client business names you do not want associated publicly
# Domain names for private services

# === Infrastructure ===
# Public IP addresses of your servers (any VPS or cloud provider)
# Mesh VPN IPs on your private network
# Hostnames that resolve to private services

# === Knowledge base hints ===
# Directory names that reveal personal structure (life/, my-notes/, etc.)
# Specific summary.md entity names that would dox a project

# === Vendor identifiers ===
# Team IDs, organization slugs, billing account names
