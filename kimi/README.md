# Kimi Code route

Kimi Code uses its native managed provider and OAuth login. config.example.toml records the model aliases, context and thinking settings, and search and fetch service shape without credentials. AGENTS.md carries Kimi-specific instructions; apply it with the repository's shared constitution using the client's supported instruction mechanism.

Check the selected account, provider, model, and metering before a launch. Authentication storage stays in the native client profile. This folder contains configuration and instruction examples, not a launcher.
