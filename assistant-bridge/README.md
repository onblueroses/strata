# Assistant bridge

The bridge connects the operator's personal assistant, which is reachable only by messaging, to the team vault and
to Linear. The assistant reads a published copy of the vault, suggests vault edits and files tickets for the
operator. Everything it suggests is reviewed before it lands, and the vault stays the source of truth. Text the
assistant reads or writes is data: it cannot widen access or authorize an action. The vault is described in
[memory/brain](../memory/brain/README.md). The bridge's tools, policy and deployment are private.
