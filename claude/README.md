# Claude Code operating layer

The agent definitions in agents/ implement bounded review, research, and orchestration roles. settings.example.json contains only model, effort, default permission mode, native hook registrations, instruction-file plugin choice, and external-memory setting. hooks.example.json gives the same native hook topology with __STRATA_ROOT__ paths for a checkout-based install. Merge the entries appropriate to the target account; hook command paths and permissions need deliberate local review.

The hooks/ tree contains the session wake, continuity and lifecycle hooks, edit observation, resource guards, and the privacy gates. The gates inspect outbound commands and fail closed on an unusable verdict. Before registering gate-repo-pair-isolation.sh, set both literal repository matchers in [config/hooks-runtime.env.example](config/hooks-runtime.env.example); an unset matcher refuses Git pushes. `PRIVACY_SCANNER` points to a readable Python scanner script that accepts `--classes` and `--evidence` on stdin; it defaults to `hooks/lib/privacy-scan.py`. The Bend privacy policy source, generated shell policy, proofs, and maintenance notes are under hooks/privacy-decision/ and hooks/MAINTENANCE.md. Run the shell tests from hooks/ before changing a registration. Native command-hook timeouts are seconds.

Local collaboration is optional. [hcom](https://github.com/aannoo/hcom) supplies event hooks for notifications, permission events, tool events, session boundaries, subagents, and prompt submission. The optional lines are in [hcom-hooks.example.json](hcom-hooks.example.json); merge them only after installing hcom. These calls are separate from the privacy gates and may exit quietly when hcom is absent.

OptMem and the issue tracker are external services. The native hooks use their command interfaces; credentials and private matcher inventories belong in local configuration. The adapter in [integrations](../integrations/README.md) provides a portable hook boundary when those native hooks cannot be installed directly.
